# Thème Solfito pour Claude

Les couleurs de l'appli Solfito (violet, orange, doré) dans l'appli Claude, en clair et en sombre.

## Installer

Dans l'appli Claude (bureau) : clique sur **+** à côté de la zone de message → **Plugins** → **Ajouter une marketplace** :
`ricocrocher-collab/solfito-robot`, puis ajoute le plugin **solfito-theme**.

Dans un terminal Claude Code :

```
/plugin install solfito-theme --marketplace ricocrocher-collab/solfito-robot
```
